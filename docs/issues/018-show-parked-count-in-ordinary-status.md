# Show parked archive count in ordinary status

- Status: proposed
- Category: enhancement
- Created: 2026-10-02
- Owner: unassigned

## Problem

Expired locators have no automatic retention deadline. PR #23 reports valid parked remainder only during explicit repair, so archive growth between repairs is invisible to operators.

## Outcome

`/adam:status` shows the current parked archive size without requiring repair or activating parked work.

## Scope

### Included

- Obtain an ordinary-status count using directory listing only, without reading/decoding snapshots.
- Clearly label this as an archive-file count rather than a count of validated/recoverable locators; distinguish it from the latest explicit-repair result.
- Treat a missing archive as empty and make unsafe/unreadable directory state visible without following symlinks.
- Retain safe directory validation and avoid lazy Neo4j initialization just to count local files.

### Excluded

- Archive decoding, source ownership queries, sidecar reads, recovery, or acknowledgement during ordinary status.
- Archive enumeration in background worker pending/idle/retry checks or ordinary lifecycle drains.
- Retention limits, automatic cleanup, producer/model work, version or release changes.

## Acceptance criteria

- [ ] Ordinary `/adam:status` reflects parked files added/removed since the last explicit repair, without requiring another repair.
- [ ] Count includes only defined archive snapshot filename candidates; temporary files and unrelated directory entries do not inflate it. The counting convention is documented.
- [ ] Listing does not decode snapshots or imply they are valid; malformed candidates remain counted and untouched.
- [ ] Missing archive reports zero; unsafe/unreadable archive reports unavailable/error rather than following it or silently claiming zero.
- [ ] Status counting does not initialize Neo4j, acquire a recovery workflow, requeue work, or change background pending/idle behavior.
- [ ] Deterministic tests verify listing-only behavior, freshness, missing/unsafe directories, and no recovery side effects.

## Validation

Not implemented. Add status regression coverage before implementation, including checks that snapshot decoding and graph initialization are not invoked.
