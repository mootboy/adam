# Bound retries for never-mirrored memory sources

> *This was generated by AI during triage.*

- Status: done
- Created: 2026-10-02
- Category: bug
- Owner: coding agent

## Problem

PR #21 review found that a producer-memory notification can keep the detached worker alive indefinitely if its source session is never mirrored. `ensure-memory-source!` reports missing ownership as transient; failed drains reject and detached mode retries at the 60-second backoff cap without a production attempt/age limit. Healthy groups still progress and the lease is released during sleep, but the idle retry process never finishes.

## Outcome

Retain short-lived missing-source retries for reversed hook ordering, while eventually acknowledging notifications for a demonstrably absent source with a logged `source-never-mirrored` reason. Implement in a small follow-up PR, not the step-6 lease-scope correction.

## Scope

- Use a 10-minute default per-notification queued-age window, configurable through `ADAM_MEMORY_SOURCE_WAIT_MS` (1000–86400000 ms), with immutable queued timestamps across restarts.
- Apply expiry only when the ownership check actually confirms an absent source, not when Neo4j is unreachable or initialization, synchronization, or projection fails.
- Acknowledge only expired notifications, preserving all mirrored source/sidecar state and allowing a later fresh notification after import to reconcile normally.
- Bound diagnostics and continue healthy producer/source groups.

## Acceptance criteria

- [x] Reversed hook order converges inside the chosen retry window without dropping a notification.
- [x] A permanently absent source expires with `source-never-mirrored` diagnostics and allows the detached worker to exit.
- [x] Backend outages and projection failures do not trigger absent-source expiry.
- [x] Restart and repeated/coalesced notifications cannot accidentally reset or prematurely exhaust the policy.
- [x] Expiry never conflicts/deletes mirrored graph state; a fresh notification after source import repairs successfully.
- [x] Deterministic clock/retry coverage pins the boundary and default policy.
